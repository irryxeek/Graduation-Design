# 项目开发过程中遇到的困难

## 记录日期
2026-02-25

---

## 一、数据获取与处理

### 1.1 COSMIC-2数据获取受限
- CDAAC数据下载需要注册账号，部分数据需要申请权限
- 数据量有限，最终只获取到约2000个有效样本

### 1.2 ERA5再分析数据匹配
- 掩星观测与ERA5格点的时空匹配较复杂
- 需要处理不同数据源的坐标系统和时间格式差异

### 1.3 质量控制筛选
- 原始数据中存在大量异常值，需要设计多级QC流程
- QC阈值的选择需要反复调试，过严导致样本不足，过松导致数据质量差

---

## 二、模型训练

### 2.1 多变量数值尺度差异
- 温度(200-300K)、气压(0.01-1000hPa)、湿度(0-0.02kg/kg)数值范围差异巨大
- 简单的Z-Score标准化无法有效处理气压的6个数量级跨度
- 湿度数值过小，在联合训练中信号被淹没

### 2.2 气压反演低层误差大
- 0-10km层气压RMSE高达140.75hPa
- 原因：未对气压做对数变换，线性标准化效果差

### 2.3 湿度反演基本失效
- 相关系数接近0，模型未能学到有效信息
- 原因：湿度仅在低层有意义，高层接近0，有效信息稀疏

### 2.4 训练收敛问题
- 早期训练出现梯度爆炸，需要添加梯度裁剪
- 多变量联合训练时损失权重难以平衡

---

## 三、评估与对比

### 3.1 缺乏传统方法基线
- 1D-Var等传统方法实现复杂，未能在项目中复现
- 只能引用文献数据进行对比

### 3.2 评估指标选择
- 逐高度层计算相关系数时，部分层预测值方差过小导致结果异常
