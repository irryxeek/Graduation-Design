## 1. 项目背景

### 1.1 GNSS-RO 掩星技术

GNSS 无线电掩星（Radio Occultation）是一种利用卫星信号弯曲来探测大气的技术：

```
GPS/GNSS 卫星
     │
     │  信号在大气中弯曲
     │   ↘
     │    ↘  ← 弯曲角 α(a)：信号偏转多少度
     │     ↘
            LEO 低轨卫星（如 FY-3D）
```

当 GNSS 信号穿过大气层时，不同高度的大气密度不同，导致信号发生折射弯曲。通过精确测量这个弯曲角剖面 $\alpha(a)$（其中 $a$ 是冲击参数/高度），可以反推大气的温度、气压等物理量。

### 1.2 反演问题：从弯曲角到大气廓线

```
输入（已知）                    输出（需要反演）
─────────────────────          ─────────────────────
弯曲角剖面 α(a)         →      温度廓线 T(z)
301 个高度点                   气压廓线 P(z)
(0~60 km)                      (0~60 km, 301 点)
```

**传统方法**：Abel 变换（物理反演，需要球对称假设）

**本项目方法**：扩散模型（深度学习，数据驱动）

### 1.3 项目目标

用 FY-3D GNOS 卫星的掩星观测数据，训练一个扩散模型，实现从弯曲角到温度/气压廓线的端到端反演。


| 项目 | 数值 |
|------|------|
| 原始样本（Day 001）| 3,310 个 |
| QC 通过 | 1,830 个（55.3%） |
| 最终训练 | 1,281 个 |
| 验证损失 | 0.013806 (Epoch 64) |

**问题**：
- 湿度通道（wetPf2）数据全零，无法用于湿度反演
- 样本量极少（1,830 个），模型泛化能力受限
- COSMIC-2 数据下载需要特殊权限，扩展困难

**已弃用**，相关数据保留在 `Data/Processed/` 供参考。

### 3.2 FY-3D L1 数据：碰壁

FY-3D GNOS 卫星是中国的气象卫星，数据获取相对容易（`utils/down/` 共 30,794 个文件）。

但 L1 数据是**原始观测量**，需要自行推导弯曲角：

```
L1 数据包含：
  exL1, exL2  → 附加相位 (m)
  LEO/GNSS 轨道位置和速度 (ECI 坐标系)

需要推导：
  excess phase → 电离层校正 → Doppler → 几何光学反演 → 弯曲角
```

**遭遇的技术障碍**：

使用几何光学方法（Newton 迭代）得到的弯曲角为**负值**（~-480 mrad），与预期（~5-20 mrad at 30 km）严重不符。

可能原因：
1. `exL1` 符号约定与标准软件不同
2. Doppler 计算公式中加减号错误
3. ECI 坐标系下速度投影处理有误
4. 开环追踪（50 Hz AEG 文件）需要特殊的 Phase Matching 处理

**结论**：L1 数据弯曲角推导技术难度大，**暂时放弃**，改用 L2 数据。

### 3.3 FY-3D L2 ATP 数据：找到正确路径

FY-3D GNOS **L2 ATP**（大气廓线产品）是已处理好的数据，直接包含：

|------|------|------|

| `Temp` | 温度廓线 | K |
| `Pres` | 气压廓线 | mb |
| `MSL_alt` | 海拔高度 | km |

```python
# 标准高度网格：0~60 km，301 个点

# 线性插值
temp_interp = np.interp(height_grid, msl_alt, temperature)

ba_interp   = np.interp(height_grid, msl_alt, bending_angle)
```

### 4.5 数据变换与标准化

**弯曲角**（跨越多个数量级，先做对数变换）：

```python
# Step 1: log10 变换
ba_log = np.log10(np.abs(bending_angle) + 1e-6)
# Step 2: Z-Score 标准化
ba_norm = (ba_log - mean_ba) / std_ba
```

**气压**（同样跨越多个数量级，0.07 ~ 1099.76 mb）：

```python
# Step 1: log10 变换
pres_log = np.log10(pressure)   # [-1.15, 3.04]
# Step 2: Z-Score 标准化
pres_norm = (pres_log - mean_pres) / std_pres   # [-2.09, 1.79]
```

**温度**（线性分布，直接 Z-Score）：

```python
temp_norm = (temperature - mean_temp) / std_temp
```

> **为什么气压要做对数变换？**
> 气压从地面约 1000 mb 到 60 km 高空约 0.07 mb，跨越 4 个数量级。
> 如果直接 Z-Score 标准化，低层气压会主导梯度，高层气压梯度消失，
> 模型无法学习高空气压。对数变换让各高度层的气压具有相近的学习权重。

## 5. 为什么选扩散模型

### 5.1 主流生成模型对比

| 模型 | 训练稳定性 | 生成质量 | 采样速度 | 不确定性量化 |
|------|----------|---------|---------|------------|
| GAN | 差（模式崩塌）| 高 | 快 | 难 |
| VAE | 好 | 中（模糊）| 快 | 有（隐空间）|
| Flow | 好 | 中 | 慢 | 有 |
| **Diffusion** | **好** | **高** | **慢** | **有（多次采样）**|

### 5.2 选择扩散模型的理由

1. **训练稳定**：只训练一个网络，MSE 损失，不像 GAN 需要博弈平衡
2. **条件生成自然**：弯曲角作为条件，可以通过交叉注意力灵活融合
3. **不确定性量化**：对同一输入多次采样，得到预测分布，在大气科学中有价值
4. **物理一致性**：扩散模型对输出分布没有强假设，适合复杂的大气物理关系

### 5.3 反演问题的特殊性

大气反演本质是**病态问题**（ill-posed）：
- 同一个弯曲角剖面可能对应多种温度/气压廓线（解不唯一）
- 传统方法需要先验约束（如球对称假设）

扩散模型天然适合病态问题，因为它学习的是**条件概率分布** $p(廓线|弯曲角)$，而不是单点估计。

## 6. 扩散模型原理（DDPM）

### 6.1 核心思想

扩散模型由两个过程组成：

```
前向过程（加噪，训练时用）：
  廓线 x₀ → x₁ → x₂ → ... → x₁₀₀₀（纯高斯噪声）
            +ε   +ε           +ε

反向过程（去噪，推理时用）：
  纯噪声 x₁₀₀₀ → x₉₉₉ → ... → x₁ → x₀（预测的廓线）
                 -ε̂          -ε̂   -ε̂
```

**训练目标**：训练网络 $\epsilon_\theta$ 预测每一步加入的噪声。

### 6.2 数学基础

**前向过程**（给 $x_0$ 加噪，得到 $x_t$）：

$$x_t = \sqrt{\bar{\alpha}_t} \cdot x_0 + \sqrt{1-\bar{\alpha}_t} \cdot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

其中 $\bar{\alpha}_t = \prod_{s=1}^{t}(1-\beta_s)$，$\beta_t$ 是噪声调度（线性从 $10^{-4}$ 到 $0.02$）。

**训练损失**（预测噪声的 MSE）：

$$\mathcal{L} = \mathbb{E}_{t, x_0, \epsilon} \left[ \| \epsilon - \epsilon_\theta(x_t, t, c) \|^2 \right]$$

其中 $c$ 是条件（弯曲角）。

**训练伪代码**：

```python
for x_0, condition in dataloader:
    t = randint(0, T=1000)           # 随机时间步
    epsilon = randn_like(x_0)        # 随机噪声

    # 前向扩散（一步到位）
    x_t = sqrt(alpha_bar[t]) * x_0 + sqrt(1 - alpha_bar[t]) * epsilon

    # 网络预测噪声（条件 = 弯曲角）
    epsilon_pred = model(x_t, t, condition)

    # MSE 损失
    loss = mse(epsilon_pred, epsilon)
    loss.backward()
```

### 6.3 DDPM 采样（推理时用）

训练完成后，从纯噪声逐步去噪：

```python
x = randn(shape)   # 从纯噪声开始

for t in range(T-1, -1, -1):   # 1000 步反向
    epsilon_pred = model(x, t, condition)

    # 还原均值
    mu = (1/sqrt(alpha[t])) * (x - (beta[t]/sqrt(1-alpha_bar[t])) * epsilon_pred)

    # 加随机噪声（最后一步除外）
    if t > 0:
        x = mu + sqrt(beta[t]) * randn_like(x)
    else:
        x = mu

return x   # 预测的廓线
```

**缺点**：需要调用网络 1000 次，推理慢（5577 样本需 36 分钟）。

### 6.4 DDIM 加速采样（理论上更快，实践中失败）

DDIM（Song et al., ICLR 2021）发现：通过设计非马尔可夫采样过程，可以跳步采样（50 步而不是 1000 步），同时复用 DDPM 训练的模型权重。

```python
# 从 1000 步中均匀选 50 步
timesteps = linspace(999, 0, 50)

for t_curr, t_prev in zip(timesteps[:-1], timesteps[1:]):
    epsilon_pred = model(x, t_curr, condition)

    # 预测 x_0
    x_0_pred = (x - sqrt(1 - alpha_bar[t_curr]) * epsilon_pred) / sqrt(alpha_bar[t_curr])

    # 直接跳到 t_prev
    x = sqrt(alpha_bar[t_prev]) * x_0_pred + sqrt(1 - alpha_bar[t_prev]) * epsilon_pred
```

> **⚠️ 注意**：在本项目中，DDIM 50 步采样**完全失败**（CC ≈ 0，RMSE 爆炸）。
> 原因尚未定位。请始终使用 DDPM 1000 步采样。详见[第 10 节](#10-推理与评估ddpm-vs-ddim)。

## 7. 网络架构：条件 1D U-Net

### 7.1 整体结构

本项目使用 `EnhancedConditionalUNet1D`，参数量 1,115,651：

```
输入：
  x_t:       (B, 2, 301)  — 带噪声的廓线（温度通道 + 气压通道）
  t:         (B,)         — 时间步
  condition: (B, 1, 301)  — 弯曲角（标准化后）

输出：
  ε_pred:    (B, 2, 301)  — 预测的噪声

结构：
  ┌── 时间嵌入（正弦编码 → MLP）
  │
  ├── 条件编码器（Conv1d 提取弯曲角特征）
  │
  ├── 编码器（3 级下采样）
  │     每级：ResBlock + 交叉注意力（关注弯曲角特征）
  │
  ├── 瓶颈层（ResBlock + 自注意力）
  │
  └── 解码器（3 级上采样）
        每级：跳跃连接（拼接编码器特征）+ ResBlock
```

### 7.2 为什么用 1D 而不是 2D

| 维度 | 适用场景 | 本项目 |
|------|---------|--------|
| 2D U-Net | 图像（H×W）| ✗ |
| **1D U-Net** | **剖面/时序（长度 L）**| **✓（301 个高度层）**|

操作对应：`Conv2d` → `Conv1d`，`MaxPool2d` → `MaxPool1d`，等。

### 7.3 时间嵌入

让网络知道当前处于哪个噪声级别（$t$ 接近 0 噪声小，接近 1000 噪声大）：

```python
class SinusoidalTimeEmbedding(nn.Module):
    def forward(self, t):
        half_dim = self.dim // 2
        emb = math.log(10000) / (half_dim - 1)
        emb = torch.exp(torch.arange(half_dim) * -emb)
        emb = t[:, None] * emb[None, :]
        return torch.cat([torch.sin(emb), torch.cos(emb)], dim=-1)
```

### 7.4 交叉注意力：条件融合的关键

**自注意力** vs **交叉注意力**：

| 类型 | Query | Key/Value | 作用 |
|------|-------|-----------|------|
| 自注意力 | 廓线特征 | 廓线特征 | 廓线内部各高度层交互 |
| **交叉注意力** | **廓线特征** | **弯曲角特征** | **廓线"查询"弯曲角信息** |

```python
class CrossAttention1D(nn.Module):
    def forward(self, x, cond):
        # x:    (B, L, C) — 当前生成的廓线特征
        # cond: (B, L, C) — 弯曲角特征
        Q = self.to_q(x)      # Query：我想要什么信息？
        K = self.to_k(cond)   # Key：弯曲角哪些部分相关？
        V = self.to_v(cond)   # Value：从弯曲角取出什么？

        attn = softmax(Q @ K.T / sqrt(d_k))
        return x + self.proj(attn @ V)  # 残差连接
```

**直观理解**：生成低层温度时，模型自动关注低层弯曲角；生成高层温度时，自动关注高层弯曲角。比简单拼接更灵活。

### 7.5 残差块

```python
class ResBlock1D(nn.Module):
    def forward(self, x, t_emb):
        h = silu(conv1(x))
        h = h + time_mlp(t_emb)[:, :, None]  # 注入时间信息
        h = silu(conv2(h))
        return h + shortcut(x)               # 残差连接
```

```python
clip_grad_norm_(model.parameters(), max_norm=1.0)
```

**Early Stopping**（防止过拟合，patience=20）：

```python
# 验证损失连续 20 个 epoch 不下降则停止
if val_loss 连续20次没有改善:
    stop_training()
```

```bash
tail -f training.log
```


### 10.2 DDPM vs DDIM 对比结果

| 采样方法 | 温度 RMSE | 温度 CC | 气压 RMSE | 气压 CC | 推理时间 |
|---------|----------|---------|----------|---------|---------|
| **DDPM（1000步）** | **26.26 K** | **0.2483** | **123.44 mb** | **0.8185** | 36 分钟 ✓ |
| DDIM（50步）| 51.90 K | -0.0133 | 8097.63 mb | -0.0540 | 2 分钟 ✗ |

**DDIM 完全失败**：CC 接近 0，气压 RMSE 爆炸到 8097 mb（正常量级应为 100 级别）。根本原因尚未定位。

### 10.3 推理流程

推理时需要做**反变换**（逆标准化 + 逆对数变换），才能得到物理单位的结果：

```python
# 温度反变换（Z-Score 逆操作）
temp_pred = temp_pred_norm * std_temp + mean_temp   # 单位: K

# 气压反变换（Z-Score 逆操作 + 对数逆操作）
pres_pred = 10 ** (pres_pred_norm * std_pres_log + mean_pres_log)   # 单位: mb
```

### 10.4 评估指标

| 指标 | 公式 | 含义 |
|------|------|------|
| RMSE | $\sqrt{\frac{1}{N}\sum(y_{pred}-y_{true})^2}$ | 绝对误差（越低越好）|
| Bias | $\frac{1}{N}\sum(y_{pred}-y_{true})$ | 系统偏差（越接近 0 越好）|
| CC | Pearson 相关系数 | 廓线形状相关性（越接近 1 越好）|

|------|------|
| $x_0$ | 干净数据（原始廓线）|

| $x_T$ | 纯高斯噪声（$T=1000$）|
