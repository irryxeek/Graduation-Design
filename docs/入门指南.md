  ## 1. 生成模型概述

  ### 1.1 什么是生成模型

  生成模型（Generative Model）的目标是学习数据的概率分布 $p(x)$，从而能够生成新的、与训练数据相似的样本。

  与判别模型的对比：

  | 类型 | 目标 | 典型任务 | 代表模型 |
  |------|------|----------|----------|
  | 判别模型 | 学习 $p(y|x)$ | 分类、回归 | CNN、ResNet |
  | 生成模型 | 学习 $p(x)$ 或 $p(x|c)$ | 图像生成、数据增强 | GAN、VAE、Diffusion |

  ### 1.2 主流生成模型对比

  | 模型 | 原理 | 优点 | 缺点 |
  |------|------|------|------|
  | GAN | 生成器与判别器对抗 | 生成质量高、速度快 | 训练不稳定、模式崩塌 |
  | VAE | 变分推断、隐空间编码 | 训练稳定、有隐空间 | 生成模糊 |
  | Flow | 可逆变换 | 精确似然估计 | 计算量大、结构受限 |
  | Diffusion | 逐步去噪 | 生成质量最高、训练稳定 | 采样速度慢 |

  ### 1.3 为什么选择扩散模型

  你的项目选择扩散模型的原因：

  1. **生成质量高**：在图像生成任务上超越 GAN
  2. **训练稳定**：不存在 GAN 的模式崩塌问题
  3. **条件生成自然**：易于融入条件信息（弯曲角）
  4. **不确定性量化**：可通过多次采样估计预测不确定性

  ## 2. 扩散模型原理

  ### 2.1 核心思想

  扩散模型的灵感来自物理学中的扩散过程（如墨水在水中扩散）。

  **核心思想**：
  - 前向过程：逐步向数据添加噪声，直到变成纯高斯噪声
  - 反向过程：学习如何逐步去除噪声，从纯噪声恢复数据

  前向（加噪）：
  x₀ (干净数据) → x₁ → x₂ → ... → x_T (纯噪声)
       +ε₁      +ε₂     +ε₃

  反向（去噪）：
  x_T (纯噪声) → x_{T-1} → ... → x₁ → x₀ (干净数据)
       -ε̂T        -ε̂{T-1}      -ε̂₁

  ### 2.2 直观理解

  想象你有一张清晰的照片：

  1. **前向过程**：每一步往照片上撒一点沙子（噪声），重复 1000 次后，照片完全被沙子覆盖，看不出原来是什么
  2. **反向过程**：训练一个神经网络，学会每一步应该移除多少沙子、从哪里移除，最终恢复原始照片

  ### 2.3 数学框架

  **前向过程**定义为马尔可夫链：

  $$q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t} x_{t-1}, \beta_t I)$$

  其中 $\beta_t$ 是噪声调度参数，控制每一步添加多少噪声。

  **关键性质**：可以直接从 $x_0$ 计算任意时刻 $x_t$：

  $$q(x_t | x_0) = \mathcal{N}(x_t; \sqrt{\bar{\alpha}_t} x_0, (1-\bar{\alpha}_t) I)$$

  其中：
  - $\alpha_t = 1 - \beta_t$
  - $\bar{\alpha}_t = \prod_{s=1}^{t} \alpha_s$（累积乘积）

  这意味着：

  $$x_t = \sqrt{\bar{\alpha}_t} \cdot x_0 + \sqrt{1-\bar{\alpha}_t} \cdot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

  ## 3. DDPM 详解

  ### 3.1 DDPM 是什么

  DDPM（Denoising Diffusion Probabilistic Models）是 2020 年提出的扩散模型实现方法，奠定了现代扩散模型的基础。

  论文：Ho et al., "Denoising Diffusion Probabilistic Models", NeurIPS 2020

  ### 3.2 训练过程

  DDPM 的训练非常简单，核心是让网络学会预测噪声：

  ```python
  # DDPM 训练伪代码
  for x_0 in dataloader:  # x_0 是干净数据
      # 1. 随机采样时间步
      t = randint(0, T)  # T=1000

      # 2. 随机采样噪声
      epsilon = randn_like(x_0)

      # 3. 前向扩散：计算 x_t
      x_t = sqrt(alpha_bar[t]) * x_0 + sqrt(1 - alpha_bar[t]) * epsilon

      # 4. 网络预测噪声
      epsilon_pred = model(x_t, t)

      # 5. 计算损失（简单的 MSE）
      loss = MSE(epsilon_pred, epsilon)

      # 6. 反向传播
      loss.backward()
      optimizer.step()
```

**为什么预测噪声而不是直接预测 x_0？**

实验表明，预测噪声比预测原始数据效果更好，因为：
- 噪声的分布是标准高斯，更容易学习
- 不同时间步的噪声具有相同的统计特性

### 3.3 采样过程

训练完成后，从纯噪声开始，逐步去噪：

```python
# DDPM 采样伪代码
x_T = randn(shape)  # 从纯噪声开始

for t in reversed(range(T)):  # T-1, T-2, ..., 1, 0
    # 预测噪声
    epsilon_pred = model(x_t, t)

    # 计算均值
    mu = (1 / sqrt(alpha[t])) * (x_t - (beta[t] / sqrt(1 - alpha_bar[t])) * epsilon_pred)

    # 添加随机噪声（除了最后一步）
    if t > 0:
        z = randn_like(x_t)
        sigma = sqrt(beta[t])
        x_{t-1} = mu + sigma * z
    else:
        x_0 = mu

return x_0
```

### 3.4 噪声调度

噪声调度（Noise Schedule）决定了每一步添加多少噪声：

**线性调度**（DDPM 原始方法）：

```python
beta = linspace(beta_start=1e-4, beta_end=0.02, T=1000)
```

**余弦调度**（改进方法，效果更好）：

```python
def cosine_schedule(T):
    s = 0.008
    steps = T + 1
    x = linspace(0, T, steps)
    alphas_cumprod = cos((x / T + s) / (1 + s) * pi / 2) ** 2
    alphas_cumprod = alphas_cumprod / alphas_cumprod[0]
    betas = 1 - (alphas_cumprod[1:] / alphas_cumprod[:-1])
    return clip(betas, 0, 0.999)
```

### 3.5 DDPM 的问题

DDPM 需要 1000 步采样，速度很慢。生成一个样本需要调用神经网络 1000 次。

## 4. DDIM 加速采样

### 4.1 DDIM 是什么

DDIM（Denoising Diffusion Implicit Models）是 2021 年提出的加速采样方法。

论文：Song et al., "Denoising Diffusion Implicit Models", ICLR 2021

**核心发现**：DDPM 的前向过程不一定要是马尔可夫链，可以设计非马尔可夫过程实现跳跃采样。

### 4.2 DDIM vs DDPM

| 特性 | DDPM | DDIM |
|------|------|------|
| 采样步数 | 1000 步 | 10-100 步（可调） |
| 速度 | 慢 | 快 10-100 倍 |
| 随机性 | 每步都有随机噪声 | 可控（eta 参数） |
| 确定性 | 随机生成 | eta=0 时完全确定 |
| 训练 | 需要训练 | 使用 DDPM 训练的模型 |

### 4.3 DDIM 采样公式

DDIM 的核心公式：

$$x_{t-1} = \sqrt{\bar{\alpha}_{t-1}} \underbrace{\left( \frac{x_t - \sqrt{1-\bar{\alpha}_t} \epsilon_\theta(x_t, t)}{\sqrt{\bar{\alpha}_t}} \right)}_{\text{预测的 } x_0} + \underbrace{\sqrt{1-\bar{\alpha}_{t-1} - \sigma_t^2} \cdot \epsilon_\theta(x_t, t)}_{\text{指向 } x_t \text{ 的方向}} + \underbrace{\sigma_t \epsilon_t}_{\text{随机噪声}}$$

其中 $\sigma_t = \eta \sqrt{\frac{1-\bar{\alpha}_{t-1}}{1-\bar{\alpha}_t}} \sqrt{1 - \frac{\bar{\alpha}_t}{\bar{\alpha}_{t-1}}}$

**eta 参数的作用**：
- $\eta = 0$：完全确定性采样（DDIM）
- $\eta = 1$：等价于 DDPM
- $0 < \eta < 1$：介于两者之间

### 4.4 DDIM 采样代码

```python
def ddim_sample(model, shape, schedule, ddim_steps=50, eta=0.0):
    """
    DDIM 加速采样

    参数:
        model: 训练好的噪声预测网络
        shape: 输出形状
        schedule: 噪声调度器
        ddim_steps: 采样步数（默认 50）
        eta: 随机性参数（0=确定性）
    """
    device = next(model.parameters()).device

    # 生成时间步子序列：[999, 979, 959, ..., 19, 0]
    # 从 1000 步中均匀选取 50 步
    timesteps = torch.linspace(schedule.timesteps - 1, 0, ddim_steps).long()

    # 从纯噪声开始
    x = torch.randn(shape, device=device)

    for i in range(len(timesteps) - 1):
        t_curr = timesteps[i]      # 当前时间步
        t_prev = timesteps[i + 1]  # 上一个时间步

        # 获取 alpha 值
        alpha_bar_t = schedule.alphas_cumprod[t_curr]
        alpha_bar_prev = schedule.alphas_cumprod[t_prev]

        # 预测噪声
        epsilon_pred = model(x, t_curr)

        # 预测 x_0
        x_0_pred = (x - torch.sqrt(1 - alpha_bar_t) * epsilon_pred) / torch.sqrt(alpha_bar_t)

        # 计算 sigma
        sigma = eta * torch.sqrt((1 - alpha_bar_prev) / (1 - alpha_bar_t)) * \
                torch.sqrt(1 - alpha_bar_t / alpha_bar_prev)

        # 计算指向 x_t 的方向
        dir_xt = torch.sqrt(1 - alpha_bar_prev - sigma**2) * epsilon_pred

        # 计算 x_{t-1}
        x = torch.sqrt(alpha_bar_prev) * x_0_pred + dir_xt

        # 添加随机噪声（如果 eta > 0）
        if eta > 0 and t_prev > 0:
            noise = torch.randn_like(x)
            x = x + sigma * noise

    return x
```

### 4.5 为什么 DDIM 可以跳步

**直观理解**：

1. DDPM 的视角：每一步只能走一小步，必须经过所有中间状态
2. DDIM 的视角：先预测最终目标 $x_0$，然后直接计算任意中间状态

这就像导航：
- DDPM：必须沿着每条小路走
- DDIM：知道目的地后，可以走高速公路直达

## 5. U-Net 架构

### 5.1 U-Net 简介

U-Net 最初由 Ronneberger 等人在 2015 年提出，用于医学图像分割。因其优秀的特征提取和恢复能力，被广泛用于扩散模型。

论文：Ronneberger et al., "U-Net: Convolutional Networks for Biomedical Image Segmentation", MICCAI 2015

### 5.3 关键组件

**1. 跳跃连接（Skip Connection）**

将编码器的特征直接传递给解码器对应层，保留细节信息：

```python
# 编码时保存特征
skip_features = []
for encoder_block in self.encoders:
    x = encoder_block(x)
    skip_features.append(x)
    x = self.pool(x)

# 解码时拼接特征
for i, decoder_block in enumerate(self.decoders):
    x = self.upsample(x)
    x = torch.cat([x, skip_features[-(i+1)]], dim=1)  # 拼接
    x = decoder_block(x)
```

**2. 残差块（ResBlock）**

```python
class ResBlock(nn.Module):
    def __init__(self, in_ch, out_ch, time_emb_dim):
        super().__init__()
        self.conv1 = nn.Conv1d(in_ch, out_ch, kernel_size=3, padding=1)
        self.conv2 = nn.Conv1d(out_ch, out_ch, kernel_size=3, padding=1)
        self.time_mlp = nn.Linear(time_emb_dim, out_ch)

        # 如果通道数不同，需要投影
        if in_ch != out_ch:
            self.shortcut = nn.Conv1d(in_ch, out_ch, kernel_size=1)
        else:
            self.shortcut = nn.Identity()

    def forward(self, x, t_emb):
        h = F.silu(self.conv1(x))

        # 注入时间信息
        h = h + self.time_mlp(t_emb)[:, :, None]

        h = F.silu(self.conv2(h))

        # 残差连接
        return h + self.shortcut(x)
```

### 5.4 时间嵌入

扩散模型需要让网络知道当前处于哪个时间步，使用正弦位置编码：

```python
class SinusoidalTimeEmbedding(nn.Module):
    """
    将标量时间步 t 转换为高维向量
    使用与 Transformer 相同的正弦编码
    """
    def __init__(self, dim):
        super().__init__()
        self.dim = dim

    def forward(self, t):
        device = t.device
        half_dim = self.dim // 2

        # 计算频率
        emb = math.log(10000) / (half_dim - 1)
        emb = torch.exp(torch.arange(half_dim, device=device) * -emb)

        # 计算编码
        emb = t[:, None] * emb[None, :]
        emb = torch.cat([torch.sin(emb), torch.cos(emb)], dim=-1)

        return emb
```

**为什么需要时间嵌入？**

不同时间步的噪声程度不同：
- $t$ 接近 $T$：噪声很大，网络需要预测大的噪声
- $t$ 接近 $0$：噪声很小，网络需要预测小的噪声

网络必须知道当前时间步才能做出正确预测。

### 5.5 1D U-Net vs 2D U-Net

你的项目处理的是一维剖面数据（301 个高度层），因此使用 1D 卷积：

| 操作 | 2D U-Net（图像） | 1D U-Net（剖面） |
|------|------------------|------------------|
| 卷积 | Conv2d | Conv1d |
| 池化 | MaxPool2d | MaxPool1d |
| 上采样 | ConvTranspose2d | ConvTranspose1d |
| 输入形状 | (B, C, H, W) | (B, C, L) |

## 6. 注意力机制

### 6.1 自注意力回顾

你已经了解 Transformer 中的自注意力，这里简单回顾：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V$$

其中 Q、K、V 都来自同一个输入。

### 6.2 交叉注意力

交叉注意力（Cross Attention）是你项目的创新点之一。与自注意力不同：

| 类型 | Query 来源 | Key/Value 来源 | 作用 |
|------|------------|----------------|------|
| 自注意力 | 输入 x | 输入 x | 特征内部交互 |
| 交叉注意力 | 输入 x | 条件 c | 条件引导生成 |

```python
class CrossAttention1D(nn.Module):
    """
    交叉注意力：让生成过程关注条件信息

    在你的项目中：
    - x: 当前生成的特征（温度/气压/湿度剖面）
    - cond: 条件信息（弯曲角剖面）
    """
    def __init__(self, dim, cond_dim, heads=4):
        super().__init__()
        self.heads = heads
        self.head_dim = dim // heads
        self.scale = self.head_dim ** -0.5

        # Query 来自特征
        self.to_q = nn.Linear(dim, dim)
        # Key 和 Value 来自条件
        self.to_k = nn.Linear(cond_dim, dim)
        self.to_v = nn.Linear(cond_dim, dim)

        self.proj = nn.Linear(dim, dim)

    def forward(self, x, cond):
        """
        x: (B, L, C) - 当前特征
        cond: (B, L, C_cond) - 条件特征
        """
        B, L, C = x.shape

        # 计算 Q, K, V
        Q = self.to_q(x)      # (B, L, C)
        K = self.to_k(cond)   # (B, L, C)
        V = self.to_v(cond)   # (B, L, C)

        # 重塑为多头形式
        Q = Q.view(B, L, self.heads, self.head_dim).transpose(1, 2)
        K = K.view(B, L, self.heads, self.head_dim).transpose(1, 2)
        V = V.view(B, L, self.heads, self.head_dim).transpose(1, 2)

        # 计算注意力分数
        attn = (Q @ K.transpose(-2, -1)) * self.scale
        attn = F.softmax(attn, dim=-1)

        # 加权求和
        out = attn @ V

        # 重塑回原始形状
        out = out.transpose(1, 2).contiguous().view(B, L, C)

        # 投影 + 残差连接
        return x + self.proj(out)
```

### 6.3 交叉注意力的作用

在你的项目中，交叉注意力让模型在生成大气剖面时，能够动态关注弯曲角的不同部分：

- 生成低层温度时，可能更关注低层弯曲角
- 生成高层温度时，可能更关注高层弯曲角
- 这种动态关注比简单拼接更灵活

### 6.4 多头注意力

多头注意力让模型从不同角度关注信息：

```python
# 单头注意力：只有一种关注方式
attention = softmax(Q @ K.T) @ V

# 多头注意力：多种关注方式的组合
head_1 = softmax(Q_1 @ K_1.T) @ V_1  # 可能关注局部特征
head_2 = softmax(Q_2 @ K_2.T) @ V_2  # 可能关注全局特征
head_3 = softmax(Q_3 @ K_3.T) @ V_3  # 可能关注特定模式
...
output = concat(head_1, head_2, ...) @ W_o
```

## 7. 条件生成

### 7.1 无条件 vs 条件生成

| 类型 | 目标 | 示例 |
|------|------|------|
| 无条件生成 | 学习 $p(x)$ | 随机生成人脸 |
| 条件生成 | 学习 $p(x|c)$ | 根据文字生成图像 |

你的项目是条件生成：
- 条件 $c$：弯曲角剖面
- 输出 $x$：温度/气压/湿度剖面

### 7.2 条件注入方式

**方式 1：拼接（Concatenation）**

最简单的方式，将条件与输入直接拼接：

```python
# 输入: x_t (B, C, L)
# 条件: cond (B, C_cond, L)
x_input = torch.cat([x_t, cond], dim=1)  # (B, C + C_cond, L)
output = model(x_input, t)
```

优点：简单
缺点：条件信息只在输入层融入

**方式 2：加法（Addition）**

将条件编码后与特征相加：

```python
cond_emb = cond_encoder(cond)  # 编码条件
x = x + cond_emb  # 相加
```

优点：不增加通道数
缺点：条件和特征必须维度相同

**方式 3：交叉注意力（你的项目采用）**

条件作为 Key/Value，特征作为 Query：

```python
x = cross_attention(x, cond)
```

优点：动态关注、表达能力强
缺点：计算量较大

**方式 4：自适应归一化（AdaIN/AdaGN）**

用条件调制归一化参数：

```python
gamma, beta = condition_to_params(cond)
x = gamma * normalize(x) + beta
```

优点：轻量级、效果好
缺点：实现稍复杂

### 7.3 你项目中的条件注入

你的项目结合了多种方式：

```python
class EnhancedUNet1D(nn.Module):
    def forward(self, x, t, condition):
        # 1. 时间嵌入
        t_emb = self.time_embed(t)

        # 2. 条件编码
        cond_feat = self.cond_encoder(condition)

        # 3. 编码器（每层都有交叉注意力）
        skips = []
        for encoder, cross_attn in zip(self.encoders, self.cross_attns):
            x = encoder(x, t_emb)
            x = cross_attn(x, cond_feat)  # 交叉注意力
            skips.append(x)
            x = self.pool(x)

        # 4. 瓶颈层
        x = self.bottleneck(x, t_emb)

        # 5. 解码器（跳跃连接）
        for decoder, skip in zip(self.decoders, reversed(skips)):
            x = self.upsample(x)
            x = torch.cat([x, skip], dim=1)
            x = decoder(x, t_emb)

        return self.output(x)
```

## 8. 训练技巧

### 8.1 损失函数

扩散模型的损失函数非常简单——均方误差（MSE）：

$$\mathcal{L} = \mathbb{E}_{t, x_0, \epsilon} \left[ | \epsilon - \epsilon_\theta(x_t, t, c) |^2 \right]$$

```python
loss = F.mse_loss(noise_pred, noise_true)
```

**为什么这么简单的损失函数就能工作？**

因为扩散模型的数学推导保证了：最小化噪声预测误差等价于最大化数据的对数似然下界（ELBO）。

### 8.2 优化器选择

**AdamW**（推荐）：

```python
optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=1e-4,
    betas=(0.9, 0.999),
    weight_decay=0.01
)
```

AdamW 相比 Adam 的优势：
- 正确实现权重衰减（L2 正则化）
- 训练更稳定，泛化更好

### 8.3 学习率调度

**余弦退火（Cosine Annealing）**：

```python
scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
    optimizer,
    T_max=num_epochs,
    eta_min=1e-6
)
```

```

1e-4 ┤ ╭──╮

1e-6 ┤        ╲___
```

**带预热的余弦退火**：

```python
def get_lr(epoch, warmup_epochs=5, total_epochs=100, base_lr=1e-4, min_lr=1e-6):
    if epoch < warmup_epochs:
        # 线性预热
        return base_lr * epoch / warmup_epochs
    else:
        # 余弦退火
        progress = (epoch - warmup_epochs) / (total_epochs - warmup_epochs)
        return min_lr + 0.5 * (base_lr - min_lr) * (1 + cos(pi * progress))
```

### 8.4 梯度裁剪

防止梯度爆炸，稳定训练：

```python
# 在 loss.backward() 之后，optimizer.step() 之前
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

**为什么需要梯度裁剪？**

扩散模型在不同时间步的梯度量级可能差异很大：
- 接近 $t=0$ 时，噪声小，梯度可能很大
- 接近 $t=T$ 时，噪声大，梯度可能较小

梯度裁剪确保训练稳定。

### 8.5 Early Stopping

防止过拟合，在验证损失不再下降时停止训练：

```python
class EarlyStopping:
    def __init__(self, patience=20, min_delta=1e-4):
        self.patience = patience
        self.min_delta = min_delta
        self.counter = 0
        self.best_loss = float('inf')
        self.should_stop = False

    def __call__(self, val_loss):
        if val_loss < self.best_loss - self.min_delta:
            self.best_loss = val_loss
            self.counter = 0
        else:
            self.counter += 1
            if self.counter >= self.patience:
                self.should_stop = True

        return self.should_stop

# 使用
early_stopping = EarlyStopping(patience=20)

for epoch in range(max_epochs):
    train_loss = train_one_epoch()
    val_loss = validate()

    if early_stopping(val_loss):
        print(f"Early stopping at epoch {epoch}")
        break
```

### 8.6 指数移动平均（EMA）

EMA 可以提高生成质量，是扩散模型的标准技巧：

```python
class EMA:
    """
    指数移动平均：保存模型参数的平滑版本
    用于推理时获得更稳定的结果
    """
    def __init__(self, model, decay=0.9999):
        self.model = model
        self.decay = decay
        self.shadow = {}

        # 初始化影子参数
        for name, param in model.named_parameters():
            if param.requires_grad:
                self.shadow[name] = param.data.clone()

    def update(self):
        """每次训练步骤后调用"""
        for name, param in self.model.named_parameters():
            if param.requires_grad:
                self.shadow[name] = (
                    self.decay * self.shadow[name] +
                    (1 - self.decay) * param.data
                )

    def apply_shadow(self):
        """推理时使用影子参数"""
        for name, param in self.model.named_parameters():
            if param.requires_grad:
                param.data = self.shadow[name]

# 使用
ema = EMA(model, decay=0.9999)

for epoch in range(epochs):
    for batch in dataloader:
        loss = train_step(batch)
        loss.backward()
        optimizer.step()
        ema.update()  # 更新 EMA

# 推理时
ema.apply_shadow()
predictions = model(test_data)
```

### 9.2 模型定义模板

```python
class DiffusionModel(nn.Module):
    def __init__(self, in_channels, out_channels, base_dim=64, time_dim=128):
        super().__init__()

        # 时间嵌入
        self.time_embed = nn.Sequential(
            SinusoidalTimeEmbedding(time_dim),
            nn.Linear(time_dim, time_dim * 4),
            nn.SiLU(),
            nn.Linear(time_dim * 4, time_dim)
        )

        # 条件编码器
        self.cond_encoder = nn.Sequential(
            nn.Conv1d(1, base_dim, kernel_size=3, padding=1),
            nn.SiLU(),
            nn.Conv1d(base_dim, base_dim, kernel_size=3, padding=1)
        )

        # U-Net 主体
        self.unet = UNet1D(in_channels, out_channels, base_dim, time_dim)

    def forward(self, x, t, condition):
        """
        x: (B, C, L) - 带噪声的数据
        t: (B,) - 时间步
        condition: (B, 1, L) - 条件（弯曲角）
        """
        t_emb = self.time_embed(t)
        cond_feat = self.cond_encoder(condition)
        return self.unet(x, t_emb, cond_feat)
```

### 9.3 训练循环模板

```python
def train(model, train_loader, val_loader, schedule, config):
    device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
    model = model.to(device)

    optimizer = torch.optim.AdamW(model.parameters(), lr=config.lr)
    scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(
        optimizer, T_max=config.epochs
    )

    best_val_loss = float('inf')

    for epoch in range(config.epochs):
        # 训练
        model.train()
        train_loss = 0

        for condition, x_0 in train_loader:
            condition = condition.to(device)
            x_0 = x_0.to(device)

            # 采样时间步和噪声
            t = torch.randint(0, schedule.timesteps, (x_0.shape[0],), device=device)
            noise = torch.randn_like(x_0)

            # 前向扩散
            x_t = schedule.q_sample(x_0, t, noise)

            # 预测噪声
            noise_pred = model(x_t, t, condition)

            # 计算损失
            loss = F.mse_loss(noise_pred, noise)

            # 反向传播
            optimizer.zero_grad()
            loss.backward()
            torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
            optimizer.step()

            train_loss += loss.item()

        train_loss /= len(train_loader)

        # 验证
        model.eval()
        val_loss = 0

        with torch.no_grad():
            for condition, x_0 in val_loader:
                condition = condition.to(device)
                x_0 = x_0.to(device)

                t = torch.randint(0, schedule.timesteps, (x_0.shape[0],), device=device)
                noise = torch.randn_like(x_0)
                x_t = schedule.q_sample(x_0, t, noise)

                noise_pred = model(x_t, t, condition)
                loss = F.mse_loss(noise_pred, noise)
                val_loss += loss.item()

        val_loss /= len(val_loader)

        # 保存最佳模型
        if val_loss < best_val_loss:
            best_val_loss = val_loss
            torch.save(model.state_dict(), 'best_model.pth')

        # 更新学习率
        scheduler.step()

        print(f"Epoch {epoch}: train_loss={train_loss:.4f}, val_loss={val_loss:.4f}")
```

```python
def inference(model, condition, schedule, x_mean, x_std, y_mean, y_std,
              ddim_steps=50, eta=0.0):

    使用 DDIM 进行推理
    """
    device = next(model.parameters()).device

        condition = (condition - x_mean) / x_std
        condition = torch.FloatTensor(condition).unsqueeze(0).unsqueeze(0).to(device)

        # DDIM 采样
        shape = (1, 3, 301)  # (batch, channels, length)
        prediction = ddim_sample(model, condition, shape, schedule, ddim_steps, eta)

        prediction = prediction * y_std + y_mean

        return prediction.squeeze()
```

**扩散前向过程（diffusion.py）**：

```python
def q_sample(self, x_0, t, noise=None):
    """
    前向扩散: 给干净数据加噪

    数学公式: x_t = sqrt(α̅_t) * x_0 + sqrt(1 - α̅_t) * ε

    参数:
        x_0: 干净数据 (B, C, L)
        t: 时间步 (B,)
        noise: 噪声，如果为 None 则随机采样

    返回:
        x_t: 加噪后的数据
    """
    if noise is None:
        noise = torch.randn_like(x_0)

    # 获取对应时间步的系数
    sqrt_alpha_bar = self.sqrt_alphas_cumprod[t]
    sqrt_one_minus_alpha_bar = self.sqrt_one_minus_alphas_cumprod[t]

    # 广播到正确形状 (B,) -> (B, 1, 1)
    sqrt_alpha_bar = sqrt_alpha_bar[:, None, None]
    sqrt_one_minus_alpha_bar = sqrt_one_minus_alpha_bar[:, None, None]

    # 应用公式
    return sqrt_alpha_bar * x_0 + sqrt_one_minus_alpha_bar * noise
```

**残差块（unet.py）**：

```python
class ResBlock1D(nn.Module):
    """
    残差块: 包含时间嵌入注入

    结构:
        x → Conv → SiLU → (+time_emb) → Conv → SiLU → (+shortcut) → out
    """
    def __init__(self, in_ch, out_ch, time_emb_dim):
        super().__init__()
        self.conv1 = nn.Conv1d(in_ch, out_ch, kernel_size=3, padding=1)
        self.conv2 = nn.Conv1d(out_ch, out_ch, kernel_size=3, padding=1)
        self.time_mlp = nn.Linear(time_emb_dim, out_ch)

        # 通道数不同时需要投影
        if in_ch != out_ch:
            self.residual = nn.Conv1d(in_ch, out_ch, kernel_size=1)
        else:
            self.residual = nn.Identity()

    def forward(self, x, t_emb):
        h = F.silu(self.conv1(x))

        # 注入时间信息: 将时间嵌入加到特征上
        # t_emb: (B, time_dim) -> (B, out_ch) -> (B, out_ch, 1)
        h = h + self.time_mlp(t_emb)[:, :, None]

        h = F.silu(self.conv2(h))

        # 残差连接
        return h + self.residual(x)
```

## 附录 C：常见问题

**Q1: 为什么扩散模型比 GAN 训练更稳定？**

GAN 需要同时训练生成器和判别器，两者相互对抗，容易出现：
- 模式崩塌：生成器只生成少数几种样本
- 训练震荡：损失不收敛

扩散模型只训练一个网络，目标函数是简单的 MSE，训练非常稳定。

**Q2: 为什么预测噪声而不是直接预测 x_0？**

实验表明预测噪声效果更好，原因：
1. 噪声的分布是标准高斯，更容易学习
2. 不同时间步的噪声具有相同的统计特性
3. 预测噪声等价于预测得分函数（score function）

**Q3: DDIM 为什么可以用更少的步数？**

DDPM 是马尔可夫链，必须逐步采样。DDIM 发现可以设计非马尔可夫过程：
1. 先预测最终结果 $x_0$
2. 然后直接计算任意中间状态 $x_{t-k}$

这样就可以跳过中间步骤。

**Q4: 交叉注意力和自注意力有什么区别？**

- 自注意力：Q、K、V 都来自同一输入，用于特征内部交互
- 交叉注意力：Q 来自一个输入，K、V 来自另一个输入，用于两个序列之间的交互

在条件生成中，交叉注意力让生成过程能够"查询"条件信息。

**Q5: 如何选择 DDIM 的步数？**

- 50 步：速度和质量的良好平衡（推荐）
- 20 步：更快，质量略有下降
- 100 步：更高质量，但速度较慢
- 10 步：快速预览，质量明显下降

**Q6: eta 参数如何选择？**

- eta = 0：完全确定性，相同输入总是得到相同输出
- eta = 1：等价于 DDPM，有随机性
- 0 < eta < 1：介于两者之间

对于需要可重复结果的科学应用，推荐 eta = 0。
