## 1. 项目概述

### 1.1 研究背景

GNSS 无线电掩星（Radio Occultation, RO）技术通过测量 GNSS 信号穿越大气时产生的弯曲角，可反演大气温度、气压等垂直剖面。传统方法依赖 Abel 积分 + 1D-Var 级联流程，存在球对称假设误差累积等局限。

本项目核心技术路线：

```
FY-3D GNOS L2 ATP 弯曲角廓线
          ↓（条件输入）
  条件扩散模型（DDPM）
          ↓（端到端反演）
  大气温度 + 气压垂直廓线（0-60 km，301层）
```

### 1.2 当前实验结果（最新，2026-03）

| 采样方法 | 温度 RMSE | 温度 CC | 气压 RMSE | 气压 CC | 状态 |
|---------|----------|---------|----------|---------|------|
| **DDPM 1000步** | 26.26 K | **0.2483** | 123.44 mb | **0.8185** | ✅ 可用 |
| DDIM 50步 | 51.90 K | -0.0133 | 8097.63 mb | -0.0540 | ❌ 失败 |

- **数据**：FY-3D GNOS L2 ATP，2025年Q1（1-3月），37,171 廓线
- **测试集**：5,577 样本，独立评估
- **模型**：EnhancedConditionalUNet1D，参数量 1,115,651

| 文件格式 | NetCDF（.nc），平均约 140 KB/文件 |

**L2 ATP 文件中的关键变量**：

| 变量名 | 单位 | 说明 |
|--------|------|------|
| `Opt_Bend_ang` | rad | 优化后的弯曲角廓线（模型输入 X） |
| `Opt_Impact_parm` | km | 冲击参数（地心距离，用于高度转换） |
| `Temp` | K | 温度廓线（模型标签 Y[0]） |
| `Pres` | mb | 气压廓线（模型标签 Y[1]） |
| `MSL_alt` | km | 海拔高度 |
| `qc` | — | 质量标志（仅 qc=100 的文件被处理）|

> **为何选用 L2 而非 L1**：曾尝试从 L1 AEG 文件（超相位 + 轨道数据）自行推导弯曲角，使用几何光学法结果出现系统性负值异常（~-480 mrad，预期应为 5-20 mrad）。原因涉及超相位符号约定不明、ECI 坐标系投影方向等多重障碍，遂改用 L2 官方产品。

## 4. 模型架构

### 4.1 扩散模型数学框架

**前向加噪**（训练时随机采样任意时间步）：

```
x_t = √ᾱ_t · x_0 + √(1-ᾱ_t) · ε,    ε ~ N(0, I)
```

**反向去噪**（推理时从 t=T 逐步恢复）：

```
x_{t-1} = (1/√α_t) · [x_t - (β_t/√(1-ᾱ_t)) · ε_θ(x_t, t, c)] + σ_t·z
```

**训练目标**（噪声预测 MSE）：

```
L = E_{x_0, ε, t} [ ||ε - ε_θ(√ᾱ_t·x_0 + √(1-ᾱ_t)·ε, t, c)||² ]
```

**噪声调度**：线性调度，β₁ = 1×10⁻⁴，β_T = 0.02，T = 1000

### 4.2 EnhancedConditionalUNet1D 网络结构

**输入**：
- `x_t`：带噪声的大气廓线，形状 `(B, 2, 301)`（2通道：温度+气压）
- `t`：时间步，形状 `(B,)`
- `condition`：弯曲角廓线，形状 `(B, 1, 301)`

**网络结构**：

```
时间步 t ──→ 正弦编码(128维) ──→ MLP ──→ t_emb(128维)
                                              │
条件 c ──→ Conv1d(1→64) → SiLU ──→ cond_feat(64维)
                                              │
x_t ─────────────────────────────────────────┼──→ 编码器 L1
                                              │    ResBlock(64→128) + CrossAttn
                                              │    MaxPool(2) → (B,128,150)
                                              │         │
                                              │    编码器 L2
                                              │    ResBlock(128→256) + CrossAttn
                                              │    MaxPool(2) → (B,256,75)
                                              │         │
                                              │      瓶颈层
                                              │    ResBlock(256→256) + CrossAttn
                                              │         │
                                              │    解码器（跳跃连接）
                                              │    ConvTranspose + Concat + ResBlock
                                              │         │
                                              └────→ 输出层 Conv1d(64→2)
                                                       ↓
                                              预测噪声 ε̂ (B, 2, 301)
```

**参数量**：1,115,651（约 111 万），权重文件约 4.3 MB

### 4.3 交叉注意力机制

在每个编码器层和瓶颈层引入交叉注意力，使去噪网络动态关注弯曲角的相关部分：

```
Attention(Q, K, V) = softmax(Q·Kᵀ / √dₖ) · V

Q：来自主特征图（当前去噪状态 x_t 的特征）
K：来自条件编码（弯曲角特征 cond_feat）
V：来自条件编码（弯曲角特征 cond_feat）

输出：x' = x + W_proj · Attention(Q, K, V)  （残差连接）
```

注意力头数：4 heads，`dₖ = dim / 4`

### 4.4 关键超参数

| 参数 | 值 | 说明 |
|------|-----|------|
| T（扩散步数）| 1000 | 前向加噪总步数 |
| β_start | 1×10⁻⁴ | 噪声调度起始值 |
| β_end | 0.02 | 噪声调度终止值 |
| base_dim | 64 | U-Net 基础通道数 |
| time_dim | 128 | 时间嵌入维度 |
| out_channels | 2 | 输出通道（温度+气压） |

### 6.2 评估指标

| 指标 | 公式 | 含义 |
|------|------|------|
| RMSE | √(Σ(pred-true)²/N) | 均方根误差，越小越好 |
| Bias | Σ(pred-true)/N | 系统偏差，正值偏高，负值偏低 |
| CC | Pearson 相关系数 | 廓线形态相关性，越接近 1 越好 |
| MAE | Σ|pred-true|/N | 平均绝对误差 |

### 6.3 当前最佳测试结果

**测试集：5,577 样本，DDPM 1000 步采样**

| 变量 | RMSE | Bias | CC |
|------|------|------|----|
| 温度 | 26.26 K | -1.89 K | 0.2483 |
| 气压 | 123.44 mb | -35.21 mb | 0.8185 |

**分层误差规律**（定性）：
- 近地面（0-5 km）：气压反演最准，温度受水汽扰动影响大
- 对流层（5-12 km）：温湿耦合问题导致温度 CC 偏低
- 平流层（12-30 km）：水汽消失，但弯曲角信号衰减
- 中高层（30-60 km）：弯曲角接近噪声水平，误差随高度增大

## 7. 已知问题与调试记录

### 7.1 ❌ DDIM 采样完全失败

**现象**：将采样步数从 1000 步削减至 50 步，输出出现灾难性发散。

| 指标 | DDPM 1000步 | DDIM 50步 |
|------|------------|----------|
| 温度 CC | 0.2483 | **-0.0133** |
| 气压 CC | 0.8185 | **-0.0540** |
| 气压 RMSE | 123.44 mb | **8097.63 mb** |

**根因分析**：
- DDIM 求解非马尔可夫 ODE，步长 Δt = 1000/50 = 20，截断误差随步长平方增长
- 大气廓线数据流形可能比图像数据更弯曲（受流体静力学约束），对大步长更敏感
- 当前噪声调度（线性，β₁=1e-4，β_T=0.02）未针对大步长重标定

**调试计划**：
1. 阶梯消融：N = 500 → 200 → 100 → 50，定位 CC 急剧劣化的临界步数
2. 可视化中间状态 x_t（t=500, 200, 100），观察流形偏离时间点
3. 尝试 DPM-Solver（高阶 ODE 求解器）替代 DDIM

### 7.2 ⚠️ 温度反演精度偏低（CC = 0.25）

**现象**：气压反演 CC = 0.82，温度 CC 仅 0.25。

**物理原因**：大气折射率 N = 77.6P/T + 3.73×10⁵e/T²

- 弯曲角直接反映的是折射率积分，气压（密度）项主导量级
- 对流层中低层水汽项（湿项）与干温度项深度耦合，即"温湿模糊"问题
- 当前训练标签不含湿度，模型无法从弯曲角中分离温度与水汽贡献

**优化方向**：
- 物理损失正则化（温度递减率惩罚项）
- 多任务学习（增加辅助预测分支）

### 7.3 ⚠️ DDPM 推理速度慢

**现象**：5,577 样本的 DDPM 1000 步推理耗时约 36 分钟（单样本 0.39 秒）。

**临时方案**：批量并行推理（`--batch_size` 参数），利用 GPU 并发。

### 7.4 历史问题（已解决）

| 问题 | 状态 | 解决方案 |
|------|------|---------|
| FY-3D L1 弯曲角推导失败 | ✅ 已解决 | 改用 L2 ATP 官方产品 |
| COSMIC-2 湿度变量名不匹配 | ✅ 已解决 | 更新变量名映射（sph/Vp 等）|
| 气压长尾分布导致梯度异常 | ✅ 已解决 | log₁₀ 变换预处理 |

## 8. 常见问题 FAQ

**Q1：为什么不直接预测廓线，而要用扩散模型？**

传统回归网络（CNN/MLP）输出确定性结果，而扩散模型能捕捉大气状态的自然不确定性，通过多次采样可估计置信区间。此外，扩散模型在建模复杂多峰分布时优于直接回归。

**Q2：输出通道为什么是 2 而不是 3？**

FY-3D GNOS L2 ATP 数据不包含湿度变量（仅含温度和气压），因此模型输出为 2 通道。若使用 COSMIC-2 wetPf2 数据，可扩展至 3 通道（含湿度），但需重新训练。

**Q3：stats.npz 里存了什么？**

存储了训练集上计算的标准化统计量（均值和标准差），用于推理时反标准化：
```python
stats = np.load('Data/Processed_ATP/stats.npz')
# x_mean, x_std：弯曲角统计量
# y_mean, y_std：温度+气压统计量（形状 (2, 301)）
```

**Q4：为什么气压要做 log₁₀ 变换，温度不需要？**

气压范围跨 4 个数量级（0.07~1099 mb），直接输入会导致高层气压样本梯度被近地面高气压主导。温度范围（约 150-350 K）相对集中，Z-Score 标准化已足够。

**Q5：如何切换为旧的 COSMIC-2 数据训练？**

```bash
python src/train.py \
    --mode multi \
    --model enhanced \
    --data_dir Data/Processed   # 改为 COSMIC-2 处理后的目录
```
