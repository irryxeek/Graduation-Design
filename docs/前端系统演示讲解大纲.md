# 前端系统演示讲解大纲

## 1. 演示目标

本前端系统主要用于展示基于 GNSS 掩星弯曲角数据的大气要素反演流程。

前端不是训练平台，而是一个面向验收展示的推理与可视化界面，重点展示：

- 掩星弯曲角数据输入
- 条件扩散模型推理
- 温度、气压、湿度三变量剖面反演
- 预测结果与真值标签对比
- RMSE、Bias、CC 等指标展示
- 批量样本结果下载

## 3. 前端系统定位

本系统前端承担的是“模型推理与结果展示”功能。

后端脚本负责：

- 数据预处理
- 模型训练
- 离线全测试集评估
- 实验结果保存

前端负责：

- 加载模型权重
- 上传或选择样本
- 调用扩散模型进行反演
- 展示反演曲线
- 计算演示样本指标
- 导出预测结果和评估摘要

## 4. 数据输入方式

### 4.1 上传分析模式

上传模式适合现场演示。

推荐上传文件：

```text
samples/demo_upload_atp_wap_2025_eval16_physical.npz
```

该文件包含：

- `x`：输入弯曲角剖面
- `y`：温度、气压、湿度真值标签
- `heights`：高度网格
- `sample_indices`：样本编号
- `split`：样本来源

上传时只需要放到左侧“上传输入弯曲角”区域，右侧真值标签可以不传。

### 4.2 本地数据集模式

本地数据集模式直接读取项目中的处理后数据：

```text
Data/Processed_ATP_WAP_2025
```

包括：

- `train_x.npy / train_y.npy`
- `val_x.npy / val_y.npy`
- `test_x.npy / test_y.npy`
- `stats.npy`

本地模式适合说明系统内部数据格式和处理闭环。

## 5. 模型架构说明

当前前端固定采用：

```text
增强 U-Net（交叉注意力）
```

也就是：

```text
EnhancedConditionalUNet1D
```

该模型以弯曲角剖面作为条件输入，通过条件扩散过程生成大气要素剖面。

讲解重点：

- 输入条件：弯曲角剖面
- 输出目标：温度、气压、湿度三变量
- 网络结构：一维 U-Net
- 条件机制：交叉注意力
- 生成方式：扩散模型逐步去噪

## 6. 推理流程说明

前端推理流程如下：

1. 读取上传文件或本地样本
2. 根据 `stats.npy` 对输入进行标准化
3. 加载增强 U-Net 权重
4. 构造扩散采样过程
5. 使用 DDPM 或 DDIM 生成预测剖面
6. 将预测结果反归一化到展示空间
7. 与真值标签进行对比
8. 计算 RMSE、Bias、CC 指标

## 7. 采样方式说明

前端支持两种采样方式：

### DDPM

完整扩散采样，步数多，速度较慢，但更接近原始扩散过程。

### DDIM

快速采样，步数较少，适合现场演示。

验收演示时可以说明：

> 为保证现场演示速度，通常使用 DDIM；如果需要展示完整扩散过程，也可以切换到 DDPM。

## 8. 指标含义说明

前端展示三个主要指标：

### CC

相关系数，反映预测剖面和真值剖面的形状一致性。

数值越接近 1，说明垂直结构越相似。

### RMSE

均方根误差，反映预测值和真值之间的整体误差大小。

数值越小越好。

### Bias

平均偏差，反映模型是否存在系统性偏高或偏低。

Bias 接近 0 表示整体偏差较小。

## 9. 上下两部分结果的区别

前端结果区分为两类：

### 批量评估汇总

这是对本次上传样本的整体平均指标。

例如上传 16 条样本时，顶部显示的是 16 条样本的平均 CC、平均 RMSE 和平均 Bias。

### 单样本反演结果

下方展示的是当前选中预览样本的结果，包括：

- 单条样本指标
- 真值曲线
- 反演曲线
- 三个变量的剖面对比图

所以顶部和底部指标不完全相同。

## 10. 逐样本指标表

前端新增了逐样本指标明细表。

该表用于查看：

- 哪些样本表现较好
- 哪些样本拉低了平均指标
- 不同变量之间的误差差异
- train / val / test 样本表现是否一致

这有助于说明模型在不同样本上的稳定性和局限性。

## 11. 演示结果解释边界

需要特别说明：

> 前端上传样本的指标是小样本、单次采样、演示口径结果，不等同于论文中的完整测试集结果。

正式论文结果以离线全测试集评估报告为准。

前端主要展示系统可运行性、交互性和完整推理流程。

## 12. 当前模型表现说明

从前端演示结果看：

- 气压剖面通常较稳定
- 湿度在部分样本上表现较好，但样本间波动较大
- 温度反演难度较高，部分样本误差较明显

可以这样解释：

> 掩星弯曲角对气压结构约束较强，因此气压反演相对稳定；温度和湿度受大气状态、垂直结构和监督标签误差影响更大，生成式模型在小样本单次采样下会表现出一定波动。

## 13. 推荐演示顺序

1. 打开前端页面
2. 介绍系统功能和模型架构
3. 选择上传分析模式
4. 上传：

```text
samples/demo_upload_atp_wap_2025_eval16_physical.npz
```

5. 选择 DDIM 或 DDPM 采样
6. 设置固定随机种子
7. 点击“开始分析上传数据”
8. 讲解批量评估汇总
9. 查看逐样本指标明细
10. 展示单样本反演曲线
11. 下载预测结果和评估摘要
12. 说明完整性能以离线评估报告为准
