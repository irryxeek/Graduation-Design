## 2. 先用一句话讲清项目

本项目基于 FY-3D GNOS 掩星数据，尝试使用条件扩散模型，直接从弯曲角廓线反演大气温度和气压廓线，并将算法封装为可运行的反演系统和可视化平台。

答辩时建议始终围绕下面这条主线展开：

1. 传统 GNSS-RO 反演方法存在假设限制和误差累积问题。
2. 本项目尝试用端到端深度学习方法替代传统级联反演链路的一部分。
3. 当前已经完成数据处理、模型构建、训练验证和系统封装。
4. 当前气压反演效果较好，温度反演还有较大优化空间。

## 3. 你必须先掌握的 5 个核心问题

### 3.1 课题在做什么

课题目标是设计并实现一套基于掩星数据的气象要素反演系统，重点反演温度和气压垂直廓线。

### 3.2 为什么不用传统方法

传统流程一般是：

`弯曲角 -> Abel 变换 -> 折射率 -> 1D-Var -> 温度/气压/湿度`

这条路线存在两个主要问题：

- Abel 变换通常依赖球对称假设，在复杂大气条件下容易产生误差。
- 1D-Var 依赖背景场，整个流程链路较长，误差容易逐级传递。

本项目因此尝试使用端到端模型，直接学习：

`弯曲角廓线 -> 温度/气压廓线`

### 3.3 输入和输出是什么

- 输入：弯曲角廓线
- 输出：统一标准高度网格上的温度廓线和气压廓线

### 3.4 已经做完了什么

根据中期报告，当前已完成的主要工作包括：

- FY-3D GNOS L2 ATP 数据处理
- 7 项质量控制规则构建
- 统一高度层插值和标准化
- 条件扩散模型设计与训练
- 测试集推理评估
- Streamlit Web 平台初步实现

### 3.5 当前最重要的实验结论是什么

当前阶段最关键的结论是：

- 气压反演已经表现出较好的可行性，测试集相关系数 `CC = 0.8185`
- 温度反演效果仍然较弱，测试集相关系数 `CC = 0.2483`
- 因此可以说项目已经初步验证了方法可行性，但还没有达到最终业务应用要求

## 4. 建议的理解顺序

如果你时间很紧，不要一开始就钻代码细节。建议按照下面的顺序理解项目。

### 4.1 第一步：先理解业务链路

你必须先把整个项目流程记住：

`FY-3D GNOS L2 ATP 数据 -> 质量控制 -> 插值到统一高度层 -> 数值变换/标准化 -> 模型训练 -> 采样推理 -> 反标准化 -> 指标评估 -> Web 展示`

只要这条链路能说顺，你在答辩时就不会乱。

### 4.2 第二步：理解为什么选择 L2 而不是 L1

这是很容易被老师问到的问题。

前期项目尝试过直接使用 L1 原始数据，从超相位和轨道信息推导弯曲角，但遇到了以下问题：

- 反演结果出现明显异常
- 超相位符号约定不明确
- Doppler 频移计算涉及坐标投影处理
- 数据工程复杂度高，不利于中期阶段快速验证核心方法

因此项目转向使用官方预处理后的 L2 ATP 产品。

答辩时建议这样表述：

> 为了保证中期阶段的数据可靠性和工程可实现性，项目优先采用官方 L2 产品，先完成端到端反演框架的验证，后续再视条件考虑回到更底层数据处理链路。

### 4.3 第三步：理解数据工程

这是当前项目最扎实、最容易讲清楚的一部分。

你至少要记住这些数字：

- 原始文件数：42,871
- 有效廓线数：37,171
- 训练集：26,019
- 验证集：5,575
- 测试集：5,577
- 标准高度网格：`0-60 km`
- 层数：`301`
- 分辨率：`0.2 km`

你要能解释下面三个问题。

#### 为什么要做质量控制

因为原始观测数据中会存在异常值、物理不合理值、无效点和不完整廓线。如果不做筛选，模型会学习到错误模式，直接影响最终反演精度。

#### 为什么要插值到统一高度网格

因为不同样本的原始高度分布不完全一致，而神经网络训练通常要求输入输出维度统一，所以需要将所有廓线插值到固定的标准高度层。

#### 为什么气压要做对数变换

原始气压跨越多个数量级，数值分布极不均衡。如果直接训练，模型容易被近地面高气压样本主导，不利于稳定收敛。引入 `log10(P)` 变换后，可以压缩动态范围，改善训练稳定性。

## 5. 项目的核心实现步骤

下面是你需要掌握的实现步骤。你不用背所有代码，但必须知道每一步在做什么。

### 5.1 数据准备

数据来源为 FY-3D GNOS L2 ATP 产品，主要变量包括：

- 弯曲角 `Opt_Bend_ang`
- 温度 `Temp`
- 气压 `Pres`
- 海拔高度 `MSL_alt`

这一阶段的目标是把原始 NetCDF 文件整理成可供模型训练的标准样本。

### 5.2 质量控制

根据报告，当前使用了 7 项质量控制规则，包括：

1. 官方质量标志筛选
2. 温度物理范围约束
3. 气压物理范围约束
4. 气压单调性验证
5. 高度覆盖检查
6. 弯曲角正值及量级合理性检查
7. 插值有效点数检查

这一阶段的本质是把不可信样本尽量排除掉。

### 5.3 插值与统一表示

所有样本统一插值到 `0-60 km` 的固定高度网格，共 `301` 层。

这样做的好处是：

- 模型输入输出维度统一
- 后续批量训练更方便
- 多个样本之间可以直接比较

### 5.4 数值变换与标准化

根据报告，当前主要做了以下处理：

- 弯曲角做对数相关变换
- 气压做 `log10(P)` 变换
- 温度保持原值
- 最后进行 Z-Score 标准化

这一阶段的作用是让不同变量进入更适合神经网络训练的数值区间。

### 5.5 数据集划分

样本按照 `7:1.5:1.5` 划分为训练集、验证集和测试集。

这一步的作用：

- 训练集用于参数学习
- 验证集用于调参和模型选择
- 测试集用于最终客观评估

### 5.6 模型构建

项目采用的是条件扩散模型，核心去噪网络是增强型一维条件 U-Net。

你不需要在短时间内完全掌握扩散模型的全部数学推导，但要知道下面几个点：

- 扩散模型本质上是一种逐步去噪生成的框架
- 项目将大气廓线视为一维序列信号
- 模型输入条件是弯曲角廓线
- 模型输出目标是温度和气压廓线
- 去噪网络负责在每个时间步恢复更接近真实分布的廓线

答辩时可以这样描述：

> 本项目将大气垂直廓线建模为一维序列，并采用条件扩散模型学习弯曲角到温度、气压廓线的非线性映射关系。

### 5.7 模型训练

训练阶段的核心工作是：

- 输入标准化后的条件信息和目标廓线
- 在噪声扰动框架下训练模型学习恢复真实廓线
- 通过验证集监控收敛情况

根据中期报告，目前：

- 训练样本数为 `26,019`
- 最优验证损失为 `0.014280`

### 5.8 推理与结果恢复

推理时，模型通过多步去噪逐渐生成目标廓线，当前采用 DDPM `1000` 步采样。

生成结果之后，还需要做：

- 反标准化
- 气压指数还原
- 物理量层面的结果评估

### 5.9 结果评估

当前主要指标包括：

- RMSE
- Bias
- 相关系数 CC

测试集结果如下：

| 变量 | RMSE | Bias | CC |
| --- | --- | --- | --- |
| 温度 | 26.26 K | -1.89 K | 0.2483 |
| 气压 | 123.44 mb | -35.21 mb | 0.8185 |

### 5.10 系统封装与展示

项目不仅停留在模型实验，还做了工程化工作：

- 将算法封装为 Python 工具包
- 开发了 Streamlit Web 可视化平台

答辩时这一点很重要，因为它说明项目不是纯算法实验，而是在向完整系统实现推进。

## 6. 你需要重点记住的实验结论

### 6.1 数据规模扩大是有效的

报告中比较了单月数据和季度数据，结果显示随着训练样本增多：

- 验证损失下降
- 气压反演精度提升
- 温度相关性略有改善

这说明扩大训练数据规模有助于提升模型泛化能力。

### 6.2 气压效果好于温度

这是当前项目最重要的实验现象。

原因可以这样理解：

- 弯曲角与大气折射率关系密切
- 折射率中气压项贡献更直接
- 温度在低层大气中与湿度强耦合
- 仅用弯曲角且不联合湿度时，温度信号难以被充分分离

所以答辩时一定要强调：

> 当前结果说明模型对气压反演更敏感，而温度反演仍然受到温湿耦合问题限制。

### 6.3 速度是当前系统瓶颈之一

根据报告：

- 测试样本数：5,577
- 总推理时间：约 36 分钟
- 单样本平均：约 `0.39 s`

这说明当前系统在精度之外，还面临推理效率问题，因此后续才会重点研究 DDIM、DPM-Solver 等加速方案。

## 9. 老师大概率会问的问题

### 9.1 为什么选择扩散模型，而不是普通回归网络

建议回答：

扩散模型在复杂分布建模和细节恢复方面具有优势，更适合处理大气廓线这类具有层次结构和不确定性的生成式重建问题。本项目希望利用这种能力提升端到端反演效果。

### 9.2 为什么气压反演明显优于温度反演

建议回答：

因为弯曲角与折射率之间关系紧密，而折射率中的气压贡献更直接；温度在对流层中与湿度存在明显耦合，仅依靠弯曲角观测难以完全分离温度信号，因此温度反演更困难。

### 9.3 为什么没有继续直接做 L1 原始反演

建议回答：

前期已经做过尝试，但中期阶段优先保证数据可靠性和工程可推进性，因此先基于官方 L2 产品验证核心模型和系统框架。后续如果时间允许，可以继续补足更底层链路研究。

### 9.4 当前最大的风险是什么

建议回答：

主要有两个风险：一是扩散采样速度偏慢，二是温度反演精度仍不足。这也是后续工作的重点。

### 9.5 后续最关键的改进方向是什么

建议回答：

- 推理加速
- 温度精度提升
- 可能的湿度联合反演
- 物理先验约束引入
- 系统工程化完善
