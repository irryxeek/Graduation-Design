# 实验补强方案

## 1. 目标

针对当前论文存在的三类主要不足，补充一套最小但足够有说服力的实验与文本修订方案：

- 评估指标过度依赖标准化空间，缺少物理空间解释
- 缺少判别式模型基线，难以回答“为什么使用扩散模型”
- 消融与敏感性分析不足，难以支撑当前超参数选择与 DDIM 异常现象解释

本方案的原则不是无限扩展工作量，而是在当前项目基础上优先补足最影响论文可信度与答辩说服力的部分。

## 2. 总体策略

论文定位调整为：

- 验证条件扩散模型在 FY-3D GNOS ATP 到 WAP 三变量廓线反演任务中的可行性
- 分析该方法在温度、气压、湿度不同变量上的表现差异与适用边界
- 通过主实验、采样对比、基线对比和敏感性分析说明方法优势与局限

不再将论文表述为：

- 已经证明扩散模型全面优于传统方法
- 已经完成对传统 Abel + 1DVar 链路的直接实验替代
- DDIM 在所有变量上均能保持与 DDPM 一致甚至更优

## 3. 针对问题 1 的补强方案

### 3.1 补做物理空间主结果

新增物理空间评估结果，至少报告以下指标：

- 温度：RMSE、Bias、CC，单位 K
- 气压：RMSE、Bias、CC，单位 hPa
- 湿度：RMSE、Bias、CC，单位 g/kg

对应新增表格：

- 表 5-2 主实验物理空间评估结果
- 表 5-3 DDPM 1000 步与 DDIM 50 步物理空间采样对比

### 3.2 修复物理空间评估中的气压恢复逻辑

当前数据预处理对气压采用了 `log10(P)` 变换，因此在物理空间评估时必须显式恢复为 hPa。需要完成以下修正：

- 在 `src/evaluate.py` 中补充气压通道反对数恢复逻辑
- 在 `stats.npy` 与预处理脚本中明确记录 `pressure_log_transformed=True`
- 统一湿度单位为 `g/kg`，避免评估脚本与论文中继续出现 `kg/kg` 表述

### 3.3 增加按高度分段统计

针对“湿度相关系数可能被高层接近零值主导”的质疑，新增高度分段评估：

- 0–5 km
- 5–20 km
- 20–60 km

每一高度段至少报告：

- 温度：RMSE、CC
- 气压：RMSE、CC
- 湿度：RMSE、CC

建议新增：

- 表 5-4 分高度层评估结果

### 3.4 增加逐高度 profile 图

在论文中纳入逐高度误差分析图：

- 温度 RMSE/Bias profile
- 气压 RMSE/Bias profile
- 湿度 RMSE/Bias profile
- 湿度逐高度相关系数 profile

用于解释：

- 气压为何整体更稳定
- 湿度误差主要集中在哪些高度层
- 为什么整体 CC 不足以完全描述湿度质量

## 4. 针对问题 2 的补强方案

### 4.1 增加判别式模型基线

最低建议新增两类判别式基线：

- MLP
- 1D-CNN

如时间允许，可再增加：

- Transformer Encoder

基线设计要求：

- 输入与扩散模型一致，均为 ATP 弯曲角廓线
- 输出与扩散模型一致，均为温度、气压、湿度三变量剖面
- 使用相同训练/验证/测试划分
- 使用相同标准化与相同评估口径

对应新增章节与表格：

- 5.4 判别式基线对比
- 表 5-5 扩散模型与判别式基线对比结果

### 4.2 对传统物理链路采取审慎处理

当前项目基础不足以在短时间内严格完成 Abel + 1DVar 全流程重建与可信对比，因此建议：

- 不强行宣称已完成与传统链路的直接数值比较
- 在论文中明确说明，本文尚未重建完整传统反演链路
- 如有必要，仅补充文献综述层面的传统方法对比表，而非实验结果表

对应修改：

- 将“优于传统方法”的表述收敛为“验证数据驱动生成模型的可行性”
- 将“替代传统物理反演链路”的表述收敛为“作为潜在补充方案”

## 5. 针对问题 3 的补强方案

### 5.1 将当前消融扩展为最小敏感性分析

在现有三组消融基础上，至少补充以下配置：

- `[1,1,2]`, `grad=0`
- `[1,1,8]`, `grad=0`
- `[1,1,4]`, `grad=0.02`

形成最小敏感性分析集合：

- `[1,1,1]`, `grad=0`
- `[1,1,2]`, `grad=0`
- `[1,1,4]`, `grad=0`
- `[1,1,8]`, `grad=0`
- `[1,1,4]`, `grad=0.02`
- `[1,1,4]`, `grad=0.05`

用于回答：

- 为什么湿度损失权重取 `1:1:4`
- 为什么不是 `1:1:2` 或 `1:1:8`
- 为什么梯度约束取 `0.05`

### 5.2 增加数据规模敏感性分析

新增训练集规模实验：

- 30%
- 60%
- 100%

至少观察：

- 温度 RMSE / CC
- 湿度 RMSE / CC

用于说明：

- 模型性能对样本量的依赖关系
- 当前数据规模是否足以支撑主实验结论

### 5.3 增加 DDIM 异常诊断实验

针对当前 DDIM 湿度 CC 降至 0.6588 的现象，至少补充以下诊断配置：

- DDIM-50, `eta=0`
- DDIM-100, `eta=0`
- DDIM-200, `eta=0`
- DDIM-100, `eta=0.5`

用于回答：

- 湿度性能下降是由采样步数过少导致，还是由纯确定性采样导致
- 增加步数是否能恢复湿度结构相关性
- `eta > 0` 是否有助于改善湿度结构建模

建议新增：

- 表 5-6 DDIM 步数与 eta 敏感性分析

## 6. 论文文本修改建议

### 6.1 创新点重写方向

建议将创新点表述为：

- 将条件扩散模型引入 FY-3D GNOS ATP 到三变量廓线联合反演任务
- 设计了面向湿度通道的加权损失与结构约束
- 构建了集数据处理、训练、推理、评估与展示为一体的系统原型
- 通过主实验、采样对比、基线对比和敏感性分析讨论方法边界

### 6.2 结果结论重写方向

建议明确写出：

- 当前结果主要反映模型对 WAP 产品的拟合能力
- 气压整体 CC 极高，需要结合变量单调性与对数变换背景谨慎解释
- 湿度整体指标必须结合高度分段结果解读
- DDIM 与 DDPM 在不同变量上存在性能权衡，而非单向优劣关系

### 6.3 单独增加局限性说明

建议在结论末尾补充局限性：

- 监督标签来自 WAP 产品而非独立真实大气真值
- 气压目标采用 `log10(P)` 变换，整体相关系数的解释应更谨慎
- 湿度结果受高度层分布影响较大，仅用整体 CC 不足以全面判断
- 当前尚未完成与完整传统 GNSS-RO 反演链路的直接实验比较

## 7. 最小执行顺序

按“投入最少、收益最大”的顺序，建议如下：

1. 修复评估脚本，补物理空间评估与气压反对数恢复
2. 增加高度分段统计输出
3. 补做 DDIM 步数与 eta 诊断
4. 实现并训练 MLP 与 1D-CNN 基线
5. 补做权重比与梯度约束敏感性分析
6. 统一更新论文正文、表格、图和结论措辞

## 8. 最低可交付版本

若时间有限，建议至少完成以下四项：

- 物理空间主实验评估
- 分高度层评估
- 一个判别式基线（至少 MLP）
- DDIM 步数与 eta 诊断

完成以上四项后，论文的可信度、说服力和答辩稳健性都会明显提升。
