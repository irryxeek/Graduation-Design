# 最小可答辩补实验：扩散模型不确定性输出能力

## 1. 实验目的

针对“既然 MLP 基线更强，为什么仍然研究扩散模型”这一答辩高频问题，补充一组最小可答辩实验，用于验证当前扩散模型是否至少具备单值回归模型不直接提供的分布输出能力。

本实验不再比较点预测精度，而是考察以下问题：

- 对同一输入重复采样时，扩散模型能否输出预测分布区间；
- 不同变量、不同高度层的不确定性宽度是否存在结构性差异；
- 这些区间是否具有初步覆盖真值的能力。

## 2. 实验设置

- 脚本：`src/run_uncertainty_probe.py`
- 模型：`experiments/main_rerun_current_standard_20260419T121928Z/enhanced_ro_diffusion_best.pth`
- 数据：`Data/Processed_ATP_WAP_2025`
- 采样方式：`DDPM`
- 样本数：`5`
- 每样本重复采样次数：`5`
- 指标空间：物理空间
- 输出目录：`experiments/uncertainty_probe_20260420T095124Z`

## 4. 可支持的结论

这组实验至少支持两个结论。

第一，当前扩散模型确实不是只能输出单值预测。对同一输入做重复 DDPM 采样后，可以得到均值、标准差和 95% 预测区间，因此从模型形式上看，它具备输出预测分布的能力，这一点与当前 MLP 基线的单次点预测不同。

第二，不确定性宽度在不同变量和不同高度层上呈现出明显差异，说明模型输出的分布并非完全无结构噪声。尤其是湿度通道在 `0-5 km` 的平均区间宽度达到 `6.0611 g/kg`，明显高于 `20-60 km` 的 `0.1266 g/kg`；温度通道在低层的区间宽度也显著高于高层。这与低层大气变化更复杂、湿度波动更强的直觉基本一致，说明扩散模型至少捕捉到了一部分“哪里更不确定”的信息。

## 5. 当前不能夸大的地方

这组实验同样暴露出当前不确定性建模仍不成熟。

- 理想情况下，95% 预测区间的覆盖率应接近 `0.95`，但当前温度、气压和湿度的整体覆盖率分别只有 `0.6585`、`0.5588` 和 `0.1336`。
- 湿度区间覆盖率尤其偏低，说明当前模型给出的湿度分布仍然明显偏窄，属于“区间存在，但校准不足”。
- 因此，这组实验只能支持“扩散模型具备分布输出能力，并呈现出一定结构性不确定性”，不能支持“当前已经实现了可靠的不确定性量化”。

## 6. 论文建议写法

若将该实验写入论文或答辩回应，建议采用如下边界清晰的表述：

> 虽然当前扩散主模型在点预测精度上未优于 MLP 基线，但扩散模型能够通过重复采样输出预测分布，而不仅是单值结果。本文补充的不确定性实验表明，对同一 ATP 输入进行多次 DDPM 采样后，可以形成温度、气压和湿度的均值预测与置信区间；其中低层湿度和低层温度表现出更宽的不确定性区间，说明模型对复杂高度层具有更高的不确定性感知能力。需要指出的是，当前 95% 区间覆盖率仍明显低于理想值，表明这一路径已显示出生成式模型区别于判别式点预测模型的潜在价值，但其不确定性校准能力仍需进一步完善。
