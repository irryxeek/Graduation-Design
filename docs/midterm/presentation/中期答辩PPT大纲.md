## 3. 研究背景与问题提出
- GNSS 掩星技术在大气探测中的应用价值
- 弯曲角廓线可用于反演折射率、温度、气压和湿度
- 传统反演流程
  - `弯曲角 -> Abel 变换 -> 折射率 -> 1D-Var -> 气象要素`
- 传统方法的主要局限
  - Abel 变换依赖球对称假设
  - 1D-Var 高度依赖背景场
  - 长链路导致误差逐级累积

---

## 4. 研究目标与主要研究内容
- 研究目标
  - 构建一套基于深度学习的端到端气象要素反演系统
  - 从弯曲角廓线直接重建温度和气压廓线
- 主要研究内容
  1. 构建 FY-3D GNOS 掩星观测数据集
  2. 设计增强型条件扩散模型
  3. 完成精度评估与误差分析
  4. 实现系统封装与 Web 可视化展示

## 11. 测试结果与性能评估
- 测试策略
  - 独立测试集评估
  - 采用 DDPM 1000 步采样
- 评估指标
  - RMSE
  - Bias
  - 相关系数 CC

| 变量 | RMSE | Bias | CC |
|------|------|------|----|
| 温度 | 26.26 K | -1.89 K | 0.2483 |
| 气压 | 123.44 mb | -35.21 mb | 0.8185 |

- 初步结论
  - 气压反演可行性较强
  - 温度反演仍需进一步优化

---

## 12. 结果分析与原因解释
- 气压反演较优的原因
  - 弯曲角与折射率联系更直接
  - 气压在折射率中的贡献更明显
- 温度反演较弱的原因
  - 温度在对流层中与湿度强耦合
  - 仅依靠弯曲角难以完全分离温度信号
- 效率问题
  - 5,577 个测试样本推理约 36 分钟
  - 单样本平均约 `0.39 s`
  - 说明 DDPM 采样效率仍是系统瓶颈

## 15. 当前困难与解决方案
- 当前困难
  - 湿大气数据获取与时空匹配难度较高
  - DDIM 大步长采样存在轨迹崩溃风险
  - 温湿耦合导致温度精度提升困难
  - 当前推理速度距离实时业务应用仍有差距
- 解决方案
  - 使用 WAP 或 ERA5 作为湿度标签补充
  - 采用渐进降步实验与 DPM-Solver 替代方案
  - 引入物理约束正则化与多任务学习
  - 通过批量并行推理和模型压缩提升效率
